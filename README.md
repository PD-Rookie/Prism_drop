# Prism Drop

**Prism Drop** is a modern, mobile-ready glassmorphic puzzle game inspired by Tetris, designed with sleek translucent light geometry, responsive touch controls, soothing Web Audio API synthesized ambient soundscapes, and progressive difficulty speed scaling.

## Features
- **Glassmorphism & Neon Visuals:** Deep dark-mode aesthetic with glowing translucent prisms and fluid particle effects on line clears.
- **Soothing Ambient Soundscape:** Multi-layered synthesized chord pads and gentle crystal chimes that play continuously during gameplay.
- **Progressive Difficulty:** Brick drop speed increases automatically as you level up.
- **Mobile-Optimized:** Perfectly tailored touch buttons and responsive layout for smooth play on Android and iOS browsers.

## How to Play
1. Open `index.html` in any modern mobile or desktop web browser.
2. Use the on-screen touch controls or arrow keys to move, rotate, and drop prisms.
3. Match and clear lines to earn points and level up!
